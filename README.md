## v0.2.2 공식 문건 예시형 체험 레이어
- `사용 예시` 화면은 기존 공식 가이드라인 이미지 2장을 그대로 유지
- `직접 체험`만 공식 문건에 제시된 어획보고 조작범위에 맞춰 재구성
- 메인화면 → 어획보고 → 어획보고 목록 → 신규 어획보고/상세정보 흐름
- 신규 등록 화면에서 조업횟수·조업일·경도/위도·양륙예정항·어획물 목록을 체험
- 양륙예정항 검색을 2차 레이어로 구현
- 어획물 추가를 품종검색 → 품종선택 → 어획량 입력의 2차 레이어로 구현
- 등록 어획물 선택 시 수정/삭제 레이어 제공
- 저장 후 연습 목록으로 복귀하여 등록 결과 확인
- 문건에 없는 QR/앱 설치 안내/실제 전송 기능은 추가하지 않음

## v0.2.3 공식 UI 직접체험 보정
- 전자어획보고 체험판을 공문 「전자어획 보고 방법(예시)」 화면 이미지 기반으로 재구성
- 메인화면 / 어획보고 목록 / 상세정보 / 신규등록 / 양륙예정항 검색 / 어획물 추가 / 어획목록 수정·삭제 화면을 공식 예시 그대로 사용
- 화면 위에 투명 클릭영역을 배치하여 공문에 보이는 버튼·행을 직접 선택하도록 구현
- 메인화면의 비대상 메뉴는 클릭 반응은 제공하되, 공문에 상세화면이 없는 기능은 확장하지 않음
- 어획보고 목록 행 → 상세정보, 신규어획보고 → 등록화면, 상세정보 수정/삭제, 양륙예정항 검색, 어획물 추가·수정·삭제, 저장 흐름을 연결
- 별도의 QR/공식 앱 설치안내는 추가하지 않음
- 인위적인 ‘가상 전송 완료’ 완료화면은 제거하고, 공문 범위인 ‘저장→목록 복귀’로 마무리


## v0.2.4 — 공문 UI의 코드 기반 직접 재구현 (재개발)
- **문제 및 원인:** v0.2.3은 화면별 공문 이미지에 투명 클릭버튼을 덧댄 방식이어서, 화면 자체가 동작하는 실제 UI가 아니었습니다. 기존 v0.2.3 방법은 폐기했습니다.
- 2027 공식 가이드라인의 「전자어획 보고 방법(예시)」 2개 도판을 비교자료로 사용해, 화면의 메뉴, 헤더, 목록, 상세, 등록, 항구 검색, 어종 검색, 어획량 입력, 수정·삭제 팝업을 HTML/CSS로 직접 재작성했습니다.
- 체험 영역 `.ereport-ui` 내부에는 문서 캡처 이미지나 투명 hotspot이 없습니다. 이전 `assets/images/report-sim` 자산과 관련 JS·SW 캐시 목록을 제거했습니다.
- 신고 자료는 브라우저 메모리에만 존재하며, 실제 시스템으로 전송되지 않습니다. 새 체험을 시작하거나 페이지를 새로고침하면 초기화됩니다.
- 신규등록 → 입력 → 항구 검색 → 어종 선택 → 어획량 → 저장 → 목록/상세 → 수정 → 삭제가 실제 상태를 유지하며 작동합니다.
- 「공식 사용 예시」 메뉴의 2개 도판은 **공문 참고 이미지**로만 남겨 체험 화면과 명확히 구분했습니다.
- 기존 2027 가이드·판정·Q&A·점수·현장기록 기능은 원본 코드를 유지했습니다.
- 아직 운영서버나 행정시스템에 연동되지 않은 **개발·검증본**입니다. 의뢰처 제출/배포 전 실제 기기·브라우저 확인 및 발주처 승인 필요.
