# 수산직불제 AI PWA v0.2 Mobile

## 이번 버전 핵심 변경
- PC 브라우저에서도 **실제 스마트폰 프레임** 안에서 앱이 보이도록 UI 전면 재구축
- 실제 휴대폰에서는 프레임을 제거하고 전체화면 PWA로 자동 전환
- 확정 시안 기준: 파란 해양 테마, 3열 메뉴, 공식 Q&A 카드, 설정 리스트, 하단 5탭
- 스플래시 시안 페이지(`splash.html`) 추가
- 앱 아이콘을 **어선 + 물고기 + 방패/체크** 조합으로 재설계
- v0.1의 Q&A 40문항, Rules DB, 판정·계산 로직, 현장위키 데모, 익명 컨설팅 기록 기능 유지

## 앱 기능
1. 공식 Q&A 40문항 검색
2. 신청·단체구성 규칙판정
3. 휴어 예상 점수범위
4. 전자어획보고 참여점수
5. 부적격 비율 감액 계산
6. 현장정보(위키형 로컬 데모)
7. 현장 컨설팅 익명 기록
8. 유관기관 / 유료 / AI API 확장 설정

## GitHub Pages
저장소 루트에 전체 파일을 올린 후
`Settings → Pages → Deploy from a branch → main / root`

## 보안
실제 API Key는 GitHub 소스나 localStorage에 저장하지 않습니다.
운영판은 Cloudflare Worker 또는 기관 API Gateway의 환경변수에 저장합니다.
